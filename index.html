Firestore 雲端資料庫連線指南

專案 ID: votenew-9ec01

💡 雙軌無縫架構保障：

系統已內建「本機即時優先」機制。無論雲端是否連線，建立主題、修改內容與投票都會立即更新於您的瀏覽器本機儲存，操作絕不卡頓或遺失！

若要在多台裝置間即時同步，請依序檢查：

  1. 建立 Firestore 資料庫：前往 Firebase Console (votenew-9ec01)，點擊「組建 (Build) → Firestore Database」，若尚未建立，請點擊「建立資料庫 (Create database)」。
  2. 開啟安全規則 (Rules)：點選資料庫上方的「規則 (Rules)」分頁，將規則替換為允許讀寫： 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

* 貼上後點擊右上角的「發布 (Publish)」，重新整理此頁面即可自動完成雙向即時雲端同步！
